## abacus graph

Show the connected subgraph around a node

### Synopsis

Perform a bidirectional BFS traversal from a node and display the connected subgraph.

Returns all nodes and edges reachable within the specified depth. Use --depth to
control how far the traversal extends from the starting node.

```
abacus graph <node-id> [flags]
```

### Examples

```
  $ abacus graph "route:GET-/api/users"
  $ abacus graph "entity:User" --depth 3
  $ abacus graph "action:create-user" --depth 1 --json
```

### Options

  -h, --help        help for graph
