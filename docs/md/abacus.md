## abacus

Living application graph for Gherkin-driven BDD

### Synopsis

Abacus models your application's API surface, entities, pages, and user actions. It bridges Gherkin specs to implementation through a persistent, cumulative graph.

### Examples

```
  $ abacus init
  $ abacus scan
  $ abacus routes --match users
  $ abacus match "the user creates an account"
```

### Options

```
      --db string   Path to the database file (default ".abacus/abacus.db")
  -h, --help        help for abacus
      --json        Output in JSON format
      --quiet       Suppress non-essential output
      --verbose     Enable verbose output
```
