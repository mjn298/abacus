## abacus init

Initialize Abacus for the current project

### Synopsis

Creates the .abacus/ directory, generates a config file with auto-detected project settings, and initializes the SQLite database.

Project type and scanners are detected automatically from package.json, go.mod,
and other project files. Use --force to re-run detection on an existing project.

```
abacus init [flags]
```

### Examples

```
  $ abacus init
  $ abacus init --dir ./my-project
  $ abacus init --force
```
