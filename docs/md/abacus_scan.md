## abacus scan

Run scanners and ingest results into the graph

### Synopsis

Runs all configured scanners (or a specific one by ID) and ingests discovered nodes and edges into the graph database.

Scanners run in two phases: scan-phase discovers nodes, then link-phase resolves
cross-references between them. Results are upserted so repeated scans are safe.

```
abacus scan [type] [flags]
```

### Examples

```
  $ abacus scan
  $ abacus scan express
  $ abacus scan prisma --json
  $ abacus scan --verbose
```
